# Словарь команд и терминов DevOps

Этот файл содержит расшифровку всех аббревиатур, команд и терминов, которые встречались в курсе.

## Урок 1. Linux и терминал
* **pwd** — *Print Working Directory* (Показать рабочую директорию).
* **ls** — *List* (Список файлов).
* **cd** — *Change Directory* (Сменить директорию).
* **touch** — *Touch* (Создать пустой файл).
* **mkdir** — *Make Directory* (Создать папку).
* **rm** — *Remove* (Удалить).
* **cp** — *Copy* (Копировать).
* **mv** — *Move* (Переместить).
* **cat** — *Concatenate* (Вывести содержимое файла).
* **nano** — текстовый редактор (название бренда).
* **whoami** — *Who am I?* (Кто я? — текущий пользователь).
* **sudo** — *SuperUser DO* (Выполнить от имени суперпользователя).
* **apt** — *Advanced Package Tool* (Пакетный менеджер в Ubuntu/Debian).
* **dnf** — *Dandified YUM* (Пакетный менеджер в Fedora/CentOS).

## Урок 2. Сети
* **ping** — *Packet InterNet Groper* (Проверка доступности узла).
* **curl** — *Client URL* (Клиент для работы с URL).
* **wget** — *Web Get* (Скачивание файлов из интернета).
* **ss** — *Socket Statistics* (Статистика сокетов).
* **nslookup** — *Name Server Lookup* (Запрос IP по домену).
* **dig** — *Domain Information Groper* (Подробный запрос DNS).
* **ip** — *Internet Protocol* (Управление сетевыми интерфейсами).
* **DNS** — *Domain Name System* (Система доменных имен).

## Урок 3. Bash
* **echo** — *Echo* (Вывод текста на экран).
* **chmod** — *Change Mode* (Изменить права доступа).
* **bash** — *Bourne Again SHell* (Командная оболочка).

## Урок 4. Nginx
* **Nginx** — бренд, не расшифровывается («Энджинкс»).
* **proxy_pass** — *Proxy Pass* (Передача запроса прокси).
* **listen** — *Listen* (Слушать порт).
* **server_name** — *Server Name* (Имя сервера).
* **location** — *Location* (Расположение/путь).
* **tail** — *Tail* (Показать конец файла).

## Уроки 5-6. Docker
* **Docker** — *Docker* (Портовый рабочий).
* **FROM** — *From* (Из какого образа).
* **RUN** — *Run* (Выполнить команду).
* **COPY** — *Copy* (Копировать).
* **ENTRYPOINT** — *Entry Point* (Точка входа).
* **AS** — *As* (Как, для именования этапа).
* **volumes** — *Volumes* (Тома для хранения данных).
* **env** — *Environment* (Переменные окружения).
* **depends_on** — *Depends On* (Зависит от).
* **restart** — *Restart* (Политика перезапуска).
* **limits** — *Limits* (Ограничения ресурсов).
* **reservations** — *Reservations* (Резервирование ресурсов).
* **secrets** — *Secrets* (Секреты/пароли).

## Уроки 7-9. CI/CD и GitHub Actions
* **CI** — *Continuous Integration* (Непрерывная интеграция).
* **CD** — *Continuous Delivery/Deployment* (Непрерывная доставка/развертывание).
* **Pipeline** — *Pipeline* (Конвейер).
* **Workflow** — *Workflow* (Рабочий процесс).
* **Job** — *Job* (Задача).
* **Step** — *Step* (Шаг).
* **Runner** — *Runner* (Бегун/виртуальная машина).
* **Action** — *Action* (Действие).
* **YAML** — *YAML Ain't Markup Language* (Формат конфигурации).
* **Registry** — *Registry* (Реестр образов).
* **Tag** — *Tag* (Метка версии).

## Урок 10. Мониторинг
* **Prometheus** — титан из мифологии (бренд).
* **Grafana** — бренд (не расшифровывается).
* **Node Exporter** — *Node Exporter* (Экспортер узла).
* **Scrape** — *Scrape* (Соскребать/собирать метрики).
* **Target** — *Target* (Цель сбора метрик).

## Уроки 11-12. Kubernetes и деплой
* **Kubernetes** — от греч. «кормчий» (K8s).
* **kubectl** — *Kube Control* (Управление Kube).
* **Minikube** — инструмент для запуска локального кластера Kubernetes (сокращение от Mini + Kubernetes).
* **Pod (Под)** — минимальная единица развертывания в Kubernetes. Название происходит от англ. «стручок» (контейнеры внутри Пода, как горошины в стручке).
* **Deployment** — *Deployment* (Развертывание).
* **Service** — *Service* (Служба).
* **SSH** — *Secure Shell* (Безопасная оболочка).
* **prune** — *Prune* (Обрезать/очищать).
