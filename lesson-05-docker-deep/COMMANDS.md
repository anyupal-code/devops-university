# Справочник по Docker

## Расшифровка названий
* **Docker** — *Docker* (Докер). Название не расшифровывается (от англ. «докер» — портовый рабочий, который загружает контейнеры).
* **FROM** — *From* (Из). Указывает базовый образ.
* **RUN** — *Run* (Выполнить). Выполняет команду внутри контейнера.
* **COPY** — *Copy* (Копировать). Копирует файлы с хоста в контейнер.
* **ENTRYPOINT** — *Entry Point* (Точка входа). Команда, которая запускается при старте контейнера.
* **AS** — *As* (Как). Дает имя этапу сборки.
* **volumes** — *Volumes* (Тома). Папки для сохранения данных.
* **env** — *Environment* (Окружение). Файл `.env` содержит переменные окружения (настройки и секреты), которые передаются в контейнер.

## Основные команды
* `docker build -t my-app .` — собрать образ с именем `my-app`.
* `docker images` — показать список всех образов.
* `docker run -p 8080:8080 my-app` — запустить контейнер из образа.
* `docker ps` — показать запущенные контейнеры.
* `docker ps -a` — показать все контейнеры (включая остановленные).
* `docker stop <container_id>` — остановить контейнер.
* `docker rm <container_id>` — удалить контейнер.
* `docker rmi <image_id>` — удалить образ.
* `docker logs <container_id>` — посмотреть логи контейнера.

## Работа с томами
* `docker volume ls` — список томов.
* `docker volume rm <volume_name>` — удалить том (данные будут потеряны).

## Очистка
* `docker system prune -a` — удалить все неиспользуемые образы и контейнеры (освобождает место).
