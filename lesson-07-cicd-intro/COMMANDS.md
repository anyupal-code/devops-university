# Справочник по CI/CD

## Расшифровка названий
* **CI** — *Continuous Integration* (Непрерывная интеграция).
* **CD** — *Continuous Delivery* (Непрерывная доставка) или *Continuous Deployment* (Непрерывное развертывание).
* **Pipeline** — *Pipeline* (Конвейер). Последовательность этапов сборки, тестирования и деплоя.
* **Workflow** — *Workflow* (Рабочий процесс). Файл конфигурации для GitHub Actions.
* **YAML** — *YAML Ain't Markup Language* (Рекурсивный акроним: «YAML — не язык разметки»). Формат для написания конфигураций.

## Основы YAML
* Отступы **только пробелами** (не табами!).
* Списки обозначаются дефисом `-`.
* Пары ключ-значение: `ключ: значение`.
* Комментарии: `#`.
