# Задания к Уроку 7

## Задание 1. Теоретическая проверка
Прочитайте теорию и ответьте на вопросы (устно или в комментариях):
1. Чем отличается Continuous Delivery от Continuous Deployment?
2. Зачем нужны тесты в CI/CD?
3. Где в репозитории GitHub лежат файлы конфигурации Actions?

## Задание 2 (*). Изучение примера
Откройте [документацию GitHub Actions](https://docs.github.com/en/actions/quickstart) и найдите пример простого workflow. 
Сравните его с примером из теории. Какие шаги совпадают? Какие отличаются?

## Задание 3 (**). Подготовка репозитория
(Это задание понадобится для следующего урока)
1. Откройте ваш репозиторий с Java-проектом (Spring Boot) на GitHub.
2. В корне проекта создайте папку `.github/workflows/`.
3. Внутри создайте пустой файл `build.yml` (пока оставьте его пустым, мы заполним его на следующем уроке).

*Примечание: папки, начинающиеся с точки (`.github`), по умолчанию скрыты в файловом менеджере. Введите путь вручную или используйте терминал.*
