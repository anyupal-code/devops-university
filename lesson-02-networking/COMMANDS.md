# Справочник сетевых команд

## 1. Проверка соединения

### ping
* **Расшифровка:** от англ. *Packet InterNet Groper* (дословно: «исследователь интернет-пакетов») или просто звукоподражание эхолоту (пинг-понг).
* **Что делает:** отправляет маленькие пакеты данных на сервер и замеряет время, за которое они возвращаются обратно.
* **Команда:** `ping google.com` или `ping 8.8.8.8`.
* *Остановить выполнение:* `Ctrl+C`.

## 2. Работа с HTTP (веб-запросы)

### curl
* **Расшифровка:** *Client URL* (Клиент для работы с URL-адресами).
* **Что делает:** позволяет отправлять HTTP-запросы из терминала (как браузер, но без графики).
* **Команды:**
  * `curl http://example.com` — получить HTML-код страницы.
  * `curl -I http://example.com` — получить только заголовки ответа (статус, тип контента).

### wget
* **Расшифровка:** *Web Get* (Получить из веба).
* **Что делает:** скачивает файлы из интернета.
* **Команда:** `wget https://example.com/file.zip`.

## 3. Проверка портов

### ss
* **Расшифровка:** *Socket Statistics* (Статистика сокетов).
* **Что делает:** показывает, какие программы и на каких портах «слушают» входящие соединения.
* **Команда:** `ss -tulnp` (или `sudo ss -tulnp`, чтобы увидеть процессы).

## 4. DNS и маршрутизация

### nslookup
* **Расшифровка:** *Name Server Lookup* (Поиск на сервере имен).
* **Что делает:** узнает IP-адрес по доменному имени.
* **Команда:** `nslookup github.com`.

### dig
* **Расшифровка:** *Domain Information Groper* (Исследователь информации о домене).
* **Что делает:** то же, что `nslookup`, но с более подробным выводом.
* **Команда:** `dig github.com`.

### ip
* **Расшифровка:** *Internet Protocol* (Интернет-протокол).
* **Что делает:** управляет сетевыми интерфейсами (показывает IP-адреса, маршруты).
* **Команды:**
  * `ip a` — показать все IP-адреса компьютера.
  * `ip route` — показать таблицу маршрутизации.
