# Задания к Уроку 8

## Задание 1. Создание workflow
1. В корне вашего Java-проекта (на GitHub) создайте папку `.github/workflows/`.
2. Внутри создайте файл `build.yml` (если еще не создали).
3. Вставьте туда конфигурацию из теории (пример `Java CI`).
4. Сделайте коммит и пуш в ветку `main`.

## Задание 2. Проверка выполнения
1. Перейдите на страницу вашего репозитория на GitHub.
2. Откройте вкладку **Actions**.
3. Убедитесь, что workflow запустился и завершился успешно (зеленая галочка).
4. Откройте логи шага "Build with Maven" и посмотрите, как проходила сборка.

## Задание 3 (*). Добавление кэширования
1. Добавьте в `build.yml` шаг кэширования Maven (из теории).
2. Сделайте коммит и пуш.
3. Сравните время выполнения сборки с кэшем и без него (посмотрите в логах).

## Задание 4 (**). Запуск тестов
1. Убедитесь, что в вашем Java-проекте есть хотя бы один тест (например, `CalculatorTest`).
2. В workflow измените команду сборки на `mvn -B test` (запуск только тестов).
3. Сделайте коммит и пуш. Убедитесь, что тесты запускаются в GitHub Actions.
