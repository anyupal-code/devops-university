# Справочник по GitHub Actions

## Расшифровка названий
* **CI** — *Continuous Integration* (Непрерывная интеграция).
* **Workflow** — *Workflow* (Рабочий процесс). Файл конфигурации конвейера.
* **Job** — *Job* (Задача). Набор шагов, выполняемых на одной виртуальной машине.
* **Step** — *Step* (Шаг). Отдельная команда или действие.
* **Runner** — *Runner* (Бегун). Виртуальная машина, на которой выполняется задача.
* **Action** — *Action* (Действие). Готовый переиспользуемый скрипт (например, `setup-java`).

## Основные команды Maven (для сборки)
* `mvn clean package` — очистить, собрать и упаковать проект.
* `mvn -B clean package` — то же самое, но в batch-режиме (без интерактивных запросов, удобно для CI).
* `mvn test` — запустить только тесты.

## Просмотр логов
* В GitHub: вкладка **Actions** -> выбрать workflow -> выбрать job -> развернуть шаги.
* В терминале (если установлен `act`): `act -j build` (локальный запуск workflow).
