# Справочник по Docker Compose

## Расшифровка названий
* **Compose** — *Compose* (Составлять). Инструмент для составления и запуска многоконтейнерных приложений.
* **depends_on** — *Depends On* (Зависит от). Указывает порядок запуска сервисов.
* **restart** — *Restart* (Перезапуск). Политика перезапуска контейнера.
* **limits** — *Limits* (Лимиты). Ограничения ресурсов.
* **reservations** — *Reservations* (Резервирование). Гарантированные ресурсы.
* **secrets** — *Secrets* (Секреты). Защищенные данные (пароли, ключи).

## Основные команды
* `docker-compose up` — запустить все сервисы.
* `docker-compose up -d` — запустить в фоновом режиме (без вывода логов).
* `docker-compose up --build` — пересобрать образы и запустить.
* `docker-compose down` — остановить и удалить контейнеры.
* `docker-compose down -v` — остановить и удалить контейнеры **вместе с томами** (данные будут потеряны).
* `docker-compose logs -f` — смотреть логи всех сервисов в реальном времени.
* `docker-compose ps` — показать статус сервисов.
