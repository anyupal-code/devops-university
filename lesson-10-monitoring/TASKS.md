# Задания к Уроку 10

## Задание 1. Развертывание стека
1. Создайте папку `monitoring` и перейдите в нее.
2. Создайте файл `docker-compose.yml` (из теории).
3. Создайте файл `prometheus.yml` (из теории).
4. Запустите: `docker-compose up -d`.
5. Проверьте, что все три контейнера работают: `docker ps`.

## Задание 2. Проверка Prometheus
1. Откройте в браузере `http://localhost:9090`.
2. Перейдите в раздел `Status` -> `Targets`.
3. Убедитесь, что цель `node-exporter` в статусе `UP` (зеленая).

## Задание 3. Настройка Grafana
1. Откройте `http://localhost:3000`.
2. Войдите под `admin` / `admin`.
3. Добавьте источник данных Prometheus (`http://prometheus:9090`).
4. Импортируйте дашборд с ID `1860`.
5. Посмотрите на графики: загрузка CPU, использование памяти, сетевой трафик.

## Задание 4 (*). Метрики приложения
Настройте Prometheus на сбор метрик с вашего Java-приложения (Spring Boot Actuator).
*Добавьте в `pom.xml` зависимость `spring-boot-starter-actuator` и настройте экспорт метрик в `application.properties`.*
*(Это опциональное задание для тех, кто хочет углубиться).*
