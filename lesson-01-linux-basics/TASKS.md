# Задания к Уроку 1

## Задание 1. Знакомство с терминалом
Откройте терминал на вашем компьютере (или подключитесь к серверу по SSH) и выполните команды по очереди:
1. `pwd` (запомните, в какой папке вы находитесь).
2. `ls -la`
3. `whoami`
4. `cat /etc/os-release`

**Контрольный вопрос:** какая операционная система установлена на вашем компьютере (или сервере)? Выведите ответ в комментарии (или просто запомните).

## Задание 2. Создание структуры проекта
Давайте потренируемся создавать папки и файлы.
1. Перейдите в домашнюю директорию: `cd ~`
2. Создайте папку для тренировки: `mkdir devops-test`
3. Зайдите в неё: `cd devops-test`
4. Создайте внутри ещё две папки: `mkdir app config`
5. Создайте пустой файл конфигурации: `touch config/app.conf`
6. Проверьте, что структура создалась: `ls -R` (выведет дерево файлов).

## Задание 3 (*). Установка программы (только для локального Linux)
*Внимание: если вы на VPS с Ubuntu, используйте `sudo apt install`. Если на Fedora (локально) — `sudo dnf install`.*

Установим утилиту `htop` для мониторинга процессов.
1. Выполните `sudo apt install htop` (или `sudo dnf install htop`).
2. Запустите её: `htop`.
3. Посмотрите, как выглядят процессы (графики CPU и памяти). Выйти из `htop` можно клавишей `F10` или `q`.
