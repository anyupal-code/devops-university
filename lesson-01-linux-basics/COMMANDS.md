# Справочник команд Linux

## Расшифровка названий команд (чтобы было понятно, откуда что взялось)

* **pwd** — *Print Working Directory* (Показать рабочую директорию). Показывает, в какой папке вы сейчас находитесь.
* **ls** — *List* (Список). Показывает файлы и папки.
* **cd** — *Change Directory* (Сменить директорию). Переход в другую папку.
* **touch** — *Touch* (Касание). Создает пустой файл (или обновляет дату изменения, если файл уже есть).
* **mkdir** — *Make Directory* (Создать директорию). Создает новую папку.
* **rm** — *Remove* (Удалить). Удаляет файлы или папки.
* **cp** — *Copy* (Копировать). Копирует файлы.
* **mv** — *Move* (Переместить). Перемещает или переименовывает файлы.
* **cat** — *Concatenate* (Соединять). Выводит содержимое файла на экран (исторически использовалась для склеивания файлов).
* **nano** — текстовый редактор (название не расшифровывается, это просто имя программы, как «Блокнот»).
* **whoami** — *Who am I?* (Кто я?). Показывает имя текущего пользователя.
* **sudo** — *SuperUser DO* (Сделать от имени суперпользователя). Выполняет команду с правами администратора.
* **apt** — *Advanced Package Tool* (Продвинутый инструмент для работы с пакетами). Установка и удаление программ.

## Навигация по файловой системе
* `pwd` — показать текущую директорию (где я нахожусь).
* `ls` — показать список файлов в текущей директории.
* `ls -la` — показать список файлов, включая скрытые (с точкой в начале), с подробной информацией.
* `cd folder_name` — перейти в папку `folder_name`.
* `cd ..` — подняться на уровень выше.
* `cd ~` — перейти в домашнюю директорию.

## Работа с файлами и папками
* `touch filename.txt` — создать пустой файл.
* `mkdir folder_name` — создать папку.
* `rm filename.txt` — удалить файл.
* `rm -rf folder_name` — удалить папку и все её содержимое (использовать с осторожностью!).
* `cp file1 file2` — скопировать файл.
* `mv file1 file2` — переместить или переименовать файл.

## Просмотр содержимого файлов
* `cat filename.txt` — вывести весь текст файла на экран.
* `less filename.txt` — открыть файл для чтения (листать стрелками, выйти — `q`).
* `nano filename.txt` — открыть файл в простом текстовом редакторе (сохранить — `Ctrl+O`, выйти — `Ctrl+X`).

## Информация о системе
* `whoami` — показать имя текущего пользователя.
* `uname -a` — показать информацию о ядре системы.
* `cat /etc/os-release` — показать версию операционной системы.
* `df -h` — показать свободное место на дисках.
* `free -h` — показать использование оперативной памяти.
