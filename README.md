# DevOps: Основы

Курс по основам DevOps. От базового администрирования Linux и работы с сетями до настройки CI/CD и оркестрации контейнеров в Kubernetes.

Курс ориентирован на практическое применение инструментов и построен вокруг сквозного проекта: развертывания Java-приложения (Spring Boot) на сервере с автоматической доставкой и мониторингом.

---

## Чему вы научитесь

* Работать с командной строкой Linux (навигация, права доступа, пакетные менеджеры).
* Понимать принципы сетевого взаимодействия (IP, порты, DNS).
* Писать Bash-скрипты для автоматизации рутинных задач.
* Настраивать веб-сервер Nginx в качестве обратного прокси.
* Оптимизировать Docker-образы с помощью многоэтапной сборки.
* Организовывать сети и управлять ресурсами в Docker Compose.
* Строить CI/CD-конвейеры в GitHub Actions (сборка, тестирование, публикация образов).
* Настраивать мониторинг (Prometheus и Grafana).
* Запускать приложения в локальном кластере Kubernetes (Minikube).

## Требования для прохождения курса

* **Компьютер** с любой операционной системой (Linux, macOS, Windows).
* **Терминал** (встроенный или WSL для Windows).
* **Сервер** (облачный VPS, локальная виртуальная машина или физический сервер) с ОС Ubuntu.
* **Docker и Docker Compose** (понадобятся с 5-го урока).
* **Аккаунт на GitHub** (для работы с CI/CD в модуле 3).
* **Аккаунт на Docker Hub** (для публикации образов).

## Структура репозитория

* `lesson-XX-название/` — папки с практическим материалом для каждого урока.
    * `README.md` — теория урока, пошаговые инструкции и чек-лист.
    * `COMMANDS.md` — справочник команд и конфигураций с расшифровкой.
    * `TASKS.md` — практические задания.
* `theory/` — углубленные теоретические материалы (архитектура, принципы работы).

## Как проходить курс

1. Читаем теорию в `README.md` текущего урока.
2. При необходимости обращаемся к файлам в папке `theory/` для понимания внутренних процессов.
3. Выполняем настройку окружения (если требуется).
4. Выполняем задания из `TASKS.md`, используя команды из `COMMANDS.md`.
5. Делаем коммит после каждого пройденного урока.
