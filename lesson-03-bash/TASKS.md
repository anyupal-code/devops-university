# Задания к Уроку 3

## Задание 1. Первый скрипт
1. Создайте файл `hello.sh`.
2. Добавьте шебанг и команду `echo "Привет, DevOps!"`.
3. Сделайте его исполняемым и запустите.
**Ожидаемый вывод:** `Привет, DevOps!`

## Задание 2. Скрипт с аргументами
Создайте файл `greet.sh`. Скрипт должен принимать два аргумента (имя и язык) и выводить:
`Привет, [Имя]! Ты изучаешь [Язык].`
Запустите его: `./greet.sh Иван Bash`

**Решение:**
~~~bash
#!/bin/bash
echo "Привет, $1! Ты изучаешь $2."
~~~

## Задание 3. Проверка файла
Создайте скрипт `check_file.sh`, который проверяет, существует ли файл `test.txt` в текущей папке. Если существует — выводит "Файл найден", иначе — "Файл не найден".

**Решение:**
~~~bash
#!/bin/bash
if [ -f "test.txt" ]; then
    echo "Файл найден"
else
    echo "Файл не найден"
fi
~~~

## Задание 4 (*). Сборка Java-приложения
Представьте, что у вас есть Java-проект. Напишите скрипт `build.sh`, который:
1. Проверяет, существует ли файл `pom.xml`.
2. Если да — выводит сообщение "Начинаю сборку..." и запускает `mvn clean package`.
3. Если нет — выводит "Ошибка: pom.xml не найден".

**Решение:**
~~~bash
#!/bin/bash
if [ -f "pom.xml" ]; then
    echo "Начинаю сборку..."
    mvn clean package
else
    echo "Ошибка: pom.xml не найден"
    exit 1
fi
~~~

## Задание 5 (**). Цикл по файлам
Напишите скрипт, который перебирает все файлы `.txt` в текущей папке и выводит их имена.

**Решение:**
~~~bash
#!/bin/bash
for FILE in *.txt; do
    echo "Найден файл: $FILE"
done
