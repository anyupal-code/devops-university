# Справочник по Bash

## Расшифровка названий
* **echo** — *Echo* (Эхо). Выводит текст на экран.
* **chmod** — *Change Mode* (Изменить режим). Меняет права доступа к файлу.
* **sh** / **bash** — название оболочки (Shell).

## Создание и запуск
* `nano script.sh` — создать/открыть скрипт.
* `chmod +x script.sh` — сделать скрипт исполняемым.
* `./script.sh` — запустить скрипт.
* `bash script.sh` — запустить скрипт через интерпретатор.

## Переменные
* `NAME="value"` — создать переменную.
* `echo $NAME` — вывести значение переменной.
* `$1`, `$2` — аргументы командной строки.
* `$#` — количество аргументов.
* `$0` — имя скрипта.

## Условия
* `if [ "$a" = "$b" ]; then ... fi` — проверка на равенство строк.
* `if [ $a -eq $b ]; then ... fi` — проверка на равенство чисел.
* `if [ $a -gt $b ]; then ... fi` — больше (>).
* `if [ $a -lt $b ]; then ... fi` — меньше (<).
* `if [ -f file.txt ]; then ... fi` — файл существует.
* `if [ -d folder ]; then ... fi` — папка существует.

## Циклы
* `for i in 1 2 3; do ... done` — цикл по списку значений.
* `for FILE in *.txt; do ... done` — цикл по файлам в папке.
* `while [ $i -lt 5 ]; do ... done` — цикл с условием.

## Полезные мелочи
* `#` — комментарий (до конца строки).
* `exit 0` — завершить скрипт с кодом 0 (успех).
* `exit 1` — завершить с кодом 1 (ошибка).
