## Теория

### 1. Что такое Bash?
**Bash** (Bourne Again SHell) — это командная оболочка и язык программирования для терминала. 
Когда вы вводите команды в терминал по одной, это ручная работа. Скрипт — это файл, в котором записана последовательность команд. Вы запускаете его, и Bash выполняет всё автоматически.

### 2. Создание первого скрипта
1. Создайте файл (например, `hello.sh`).
2. В первой строке укажите **шебанг** (shebang) — путь к интерпретатору:
   ~~~bash
   #!/bin/bash
   ~~~
3. Напишите команды:
   ~~~bash
   echo "Привет, мир!"
   ~~~
4. Сделайте файл исполняемым:
   ~~~bash
   chmod +x hello.sh
   ~~~
5. Запустите:
   ~~~bash
   ./hello.sh
   ~~~

* `echo` — аналог `print` в Java. Выводит текст на экран.
* `chmod +x` — дает файлу право на выполнение (execute).
* **Важно про точку:** `./` в начале команды означает «текущая директория». Linux не ищет программы в текущей папке автоматически (в целях безопасности). Точка явно указывает: «Запусти файл, который лежит прямо здесь».

### 3. Переменные
В Bash переменные создаются без указания типа (в отличие от Java) и без пробелов вокруг знака `=`.

~~~bash
#!/bin/bash
NAME="Мир"
AGE=25

echo "Привет, $NAME! Тебе $AGE лет."
~~~

* Обращение к переменной — через `$`.
* Если в значении есть пробелы, его нужно брать в кавычки (`NAME="Иван Иванов"`).

### 4. Аргументы командной строки
Скрипт может принимать аргументы при запуске:
~~~bash
#!/bin/bash
echo "Привет, $1! Ты изучаешь $2."
~~~
Запуск:
~~~bash
./script.sh Иван Bash
~~~
Вывод: `Привет, Иван! Ты изучаешь Bash.`
* `$1` — первый аргумент, `$2` — второй и т.д.
* `$0` — имя самого скрипта.
* `$#` — количество переданных аргументов.

### 5. Условные конструкции (if)
~~~bash
#!/bin/bash
if [ "$1" = "admin" ]; then
    echo "Доступ разрешен"
else
    echo "Доступ запрещен"
fi
~~~
* `[ ... ]` — проверка условия (пробелы внутри скобок обязательны!).
* `then` — начало блока при истинном условии.
* `fi` — конец блока (if наоборот).

### 6. Циклы (for)
~~~bash
#!/bin/bash
for FILE in *.txt; do
    echo "Обрабатываем файл: $FILE"
done
~~~
* `*.txt` — шаблон (glob), который выбирает все файлы с расширением `.txt` в текущей папке.

### 7. Проверка существования файла
Часто в скриптах нужно проверить, существует ли файл или папка:
~~~bash
if [ -f "myfile.txt" ]; then
    echo "Файл существует"
else
    echo "Файла нет"
fi
~~~
* `-f` — проверка, что это файл и он существует.
* `-d` — проверка, что это директория.
