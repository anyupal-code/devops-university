# Справочник утилит

В этом файле собраны все утилиты и инструменты, которые использовались в курсе, с кратким описанием их назначения.

## 1. Базовые утилиты Linux
* **apt / dnf** — установка, обновление и удаление программ.
* **systemctl** — управление службами (запуск, остановка, перезапуск).
* **nano / vim** — текстовые редакторы для работы в терминале.
* **tail** — просмотр последних строк файла (удобно для логов).
* **chmod** — изменение прав доступа к файлам.

## 2. Сетевые утилиты
* **ping** — проверка доступности узла.
* **curl** — отправка HTTP-запросов из терминала.
* **wget** — скачивание файлов из интернета.
* **ss** — просмотр открытых портов и сокетов.
* **nslookup / dig** — проверка DNS-записей.
* **ip** — управление сетевыми интерфейсами.

## 3. Docker и Docker Compose
* **docker** — управление контейнерами и образами.
* **docker-compose** — управление многоконтейнерными приложениями.
* **docker login** — авторизация в реестре.
* **docker build** — сборка образа.
* **docker push / pull** — отправка и скачивание образов.
* **docker system prune** — очистка неиспользуемых ресурсов.

## 4. Nginx
* **nginx** — веб-сервер и обратный прокси.
* **certbot** — получение SSL-сертификатов Let's Encrypt.

## 5. CI/CD и GitHub Actions
* **git** — система контроля версий.
* **GitHub Actions** — платформа для CI/CD.
* **act** (опционально) — локальный запуск GitHub Actions.

## 6. Мониторинг
* **prometheus** — сбор и хранение метрик.
* **node-exporter** — сбор системных метрик.
* **grafana** — визуализация метрик (дашборды).

## 7. Kubernetes
* **minikube** — локальный кластер Kubernetes.
* **kubectl** — управление кластером (поды, сервисы, деплойменты).

## 8. Утилиты для деплоя
* **ssh** — удаленное подключение к серверу.
* **ssh-keygen** — генерация SSH-ключей.
* **ssh-copy-id** — копирование публичного ключа на сервер.
