# Теория: Принципы CI/CD

## 1. Непрерывная интеграция (CI)
Практика, при которой изменения кода часто интегрируются в основную ветку.  
Каждая интеграция автоматически проверяется сборкой и тестами.  
Это позволяет обнаруживать ошибки на ранних этапах и снижает риск конфликтов при слиянии.

## 2. Непрерывная доставка и развертывание (CD)
* **Continuous Delivery:** Процесс автоматической сборки и тестирования, при котором код всегда готов к развертыванию в продакшн (деплой запускается вручную).  
* **Continuous Deployment:** Полная автоматизация, при которой каждая успешная сборка автоматически развертывается на сервере без участия человека.  

## 3. Конвейер (Pipeline)
Конвейер состоит из последовательных этапов (stages): сборка, тестирование, статический анализ, упаковка (Docker build), развертывание.  
Если на одном из этапов происходит ошибка, конвейер останавливается (fail-fast).

## 4. Инструменты
GitHub Actions использует декларативный синтаксис YAML для описания workflow.  
Каждый workflow состоит из задач (jobs), которые выполняются на виртуальных машинах (runners) и содержат последовательность шагов (steps).
