# Теория: Архитектура Nginx

## 1. Обратный прокси
Обратный прокси (Reverse Proxy) — это сервер, который принимает запросы от клиентов и перенаправляет их внутренним серверам. Клиент взаимодействует только с прокси, не зная о внутренней структуре сети. Это обеспечивает балансировку нагрузки и безопасность.

## 2. Архитектура Nginx (Event-driven)
Nginx использует асинхронную, событийно-ориентированную модель обработки запросов. 
В отличие от серверов, создающих отдельный процесс или поток для каждого соединения (что приводит к высокому потреблению памяти), Nginx использует несколько рабочих процессов (workers), каждый из которых способен обрабатывать тысячи соединений одновременно с минимальными затратами ресурсов.

## 3. Фазы обработки запроса
1. Прием соединения (Listen).
2. Разбор HTTP-заголовков.
3. Применение правил маршрутизации (Location).
4. Передача запроса (Proxy Pass) или отдача статического файла.
5. Формирование ответа.

## 4. Виртуальные хосты
Nginx позволяет размещать несколько сайтов на одном сервере. Выбор конфигурации происходит на основе заголовка `Host` в HTTP-запросе (директива `server_name`).
